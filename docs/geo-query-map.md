# GEO query map — Bahari Asili Safaris

The questions travellers actually type into ChatGPT, Gemini, Perplexity, Claude and Google AI Mode, grouped by program family, with the page and section that answers each one. Built from the live program catalogue, not from a keyword tool.

**How to use this file**

- Every question must be answerable on the linked page, in the raw HTML, without JavaScript.
- If a question has no good answer, add it to the page rather than creating a new thin page.
- Do not create pages for destinations Bahari Asili does not operate.
- Re-run the baseline in `docs/geo-baseline.md` monthly and update this map when a program is added.

Anchors below refer to section ids on the page (`/safaris/{slug}#cost`, `#best-time`, `#with-children`, `#mobility`, `#packing`, `#health-safety`, `#faq`).
